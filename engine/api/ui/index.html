Assumption diff

POST /assumptions/diff — a diff by component, not by line. A reordered mapping is not a change; a changed rate is reported at the path that moved. The verdict comes from the two digests, which are the same digests an approval binds to (RFC-044), so this screen and the approval check can never disagree about whether two bases are the same.
